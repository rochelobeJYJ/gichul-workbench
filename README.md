# 기출 문항집 작업기 (gichul-workbench)

수능·모의평가 기출을 **자동으로 내려받아, 문항별로 잘라내고, 교육과정 단원에 분류해서, 인쇄용 문항집으로 만들어 주는 도구**입니다.

사회탐구 9과목, 과학탐구 8과목, 통합과학·통합사회를 지원합니다.

**처음이시면 → [사용 안내](https://rochelobeJYJ.github.io/gichul-workbench/)** (설치부터 학습지까지)

```
기출 PDF  →  문항별 이미지  →  단원 분류  →  A4 학습지
```

수업에 쓸 단원별 학습지를 만드시려고 기출 PDF를 열어 화면 캡처하고, 한글에 붙여넣고, 크기 맞추고 계셨다면 — 그 일을 대신 해 드리는 도구입니다.

---

## 이런 일을 하실 수 있습니다

- **단원별 문항집**: "지구과학Ⅱ 대기와 해양 단원 문항만 모아서 A4 학습지로" — 클릭 몇 번이면 됩니다.
- **교육과정 재구성**: 2015 개정 기출을 2022 개정 성취기준에 맞춰 다시 묶습니다. 지구과학Ⅰ·Ⅱ는 760문항 매핑이 이미 들어 있습니다.
- **기출 아카이브**: 문항 이미지, 본문, 정답, 배점, 단원을 한 번에 정리해 두고 필요할 때 꺼내 씁니다.
- **정답표까지 한 장에**: 정답을 문항 옆에 붙이거나, 학습지 끝에 정답표로 붙이거나, 아예 빼거나 — 선택하실 수 있습니다.

## 가장 쉬운 방법 — LLM에게 맡기기

이 도구는 **Claude Code나 Codex 같은 AI 코딩 도구가 읽고 알아서 쓰도록** 만들어졌습니다.
설명서를 다 읽지 않으셔도 됩니다. 폴더를 내려받아 놓고 이렇게 말씀하시면 됩니다.

> 이 폴더의 도구로 지구과학2 기출 문항집 만들어줘

> 한국지리 2020년부터 2026년까지 수능·모평 기출 받아서 단원별로 정리해줘

> 화학1 2024·2025 수능에서 산화환원 단원 문항만 골라서 학습지 만들어줘

AI가 `SKILL.md`(Claude) 또는 `AGENTS.md`(Codex)를 읽고 나머지를 알아서 처리합니다.
중간에 판단이 필요한 부분만 여쭤볼 겁니다.

## 처음 써보기 — 명령 하나

### AI(Claude Code·Codex)를 쓰고 계시면 — 여기서 끝입니다

외울 것이 없습니다. 그냥 말씀하시면 됩니다.

> 지구과학2 기출로 단원별 학습지 만들어줘

설치할 때 AI가 자동으로 찾는 자리에 넣어 두었으므로, 폴더 위치도 몰라도 됩니다.

### 직접 하시려면 — 한 줄

설치 화면에 적힌 폴더로 이동해서:

```powershell
.\gw quickstart
```

세 가지만 답하시면 됩니다. **엔터만 쳐도 되는 것이 둘**입니다.

```
  어느 과목인가요?          → 번호를 적습니다 (예: 3)
  몇 년치를 받을까요?       → 엔터 (최근 3년)
  어떤 시험을 받을까요?     → 엔터 (수능 + 6·9월 모평)
```

그다음은 기다리시면 됩니다. 다 끝나면 **브라우저 두 창이 저절로 열립니다.**

1. **확인용 이미지 한 장** — 잘라낸 문항이 한눈에 보입니다.
   ⑤번 선택지가 잘린 문항이 없는지만 봐 주세요. **이것만은 기계가 못 잡습니다.**
2. **문항집 제작기** — 여기서 학습지를 만드시면 됩니다.

실제로 걸린 시간입니다 — 생명과학Ⅰ 한 회차 **15초**, 한국지리 두 회차 **76초**.

> 💡 중간에 멈춰도 **받은 것은 지워지지 않습니다.** 화면이 어디서 멈췄고 뭘 하면 되는지 알려 드리고,
> 다시 돌리시면 이미 받은 것은 건너뜁니다.

<details>
<summary>단계를 하나씩 보고 싶으시면</summary>

`quickstart`가 이 순서로 돕니다. 따로 돌리셔도 됩니다.

```powershell
.\gw download --subject earth-science-ii --years 2024-2026 --exams 수능,6월모평,9월모평 --kinds problem,answer,solution
.\gw detect   --subject earth-science-ii
.\gw crop     --subject earth-science-ii
.\gw extract  --subject earth-science-ii
.\gw rates    --subject earth-science-ii   # 선택 — EBSi 오답률
.\gw classify --subject earth-science-ii   # 선택 — 단원 나누기
.\gw validate --subject earth-science-ii
.\gw build    --subject earth-science-ii
```

과목 이름 목록은 `.\gw subjects` 로 보실 수 있습니다.
파이썬을 이미 쓰고 계시면 `python scripts/gw.py ...` 도 그대로 됩니다.
</details>

## 작업 폴더

내려받은 PDF와 잘라낸 이미지는 **과목이 늘면 수 GB**가 됩니다.
그래서 프로그램 폴더가 아니라 **선생님이 정한 곳**에 쌓입니다.

처음 한 번만 여쭤보고 기억합니다. **엔터만 치시면 `바탕화면\기출작업`** 이 됩니다.

```powershell
.\gw where                      # 지금 어디에 쌓이고 있는지
.\gw where --set "D:\기출작업"   # 다른 곳으로 옮기기
```

> 이미 쓰고 계시던 분은 **아무것도 옮기지 않고 그대로 쓰십니다.** 묻지도 않습니다.

## 문항집 제작기 사용법

브라우저로 열면 이런 화면이 나옵니다.

**왼쪽**에서 단원이나 성취기준을 고르시면, **가운데**에 해당 문항들이 시험 시간순으로 쭉 나옵니다.

> 💡 단원 분류를 안 하신 과목에서는 왼쪽이 단원 대신 **시험 회차**로 나옵니다.
> 회차 한 줄을 누르면 그 회차 전체가 담깁니다.
처음엔 전부 선택되어 있으니, 빼고 싶은 문항의 체크만 풀어 주세요. 문항 이미지를 클릭하면 크게 볼 수 있습니다.

**오른쪽 위 옵션**에서 이런 것들을 정하실 수 있습니다.

| 옵션 | 설명 |
|---|---|
| 문항 위에 정답 표시 | 시험 정보 옆에 정답을 붙입니다. 교사용에 좋습니다 |
| 끝에 정답표 | 학습지 맨 뒤에 정답표를 붙입니다 |
| 성취기준 코드 표시 | `12지과Ⅱ03-02` 같은 코드를 함께 보여 줍니다 |
| 단원 설명 | 제목 아래에 단원명과 설명을 넣습니다 |
| 한 단에 최대 문항 수 | 2개 또는 3개. 문항이 크면 자동으로 줄어듭니다 |
| 정렬 뒤집기 | 최신 시험부터 보고 싶으실 때 |
| 문항 아래 풀이 공간 | 학생이 풀 자리를 만듭니다. 적게 / 보통 / 많이 |
| 머리말·꼬리말 | 학교명·단원명 같은 것을 넣습니다. 이름·날짜 칸도 넣으실 수 있습니다 |
| 번호 1,2,3…으로 덮어쓰기 | 원래 시험 번호 대신 순번으로 보이게 합니다 |
| 오답률 | 오답률이 일정 수준 이상인 문항만 고르거나, 어려운 순으로 정렬합니다 |

**새 옵션은 전부 기본이 꺼져 있습니다.** 켜지 않으시면 예전과 똑같이 나옵니다.

가운데 목록 위의 **검색창**에 낱말을 넣으시면 발문·`<보기>`·선택지 본문에서 찾아 줍니다. 단원 선택과 함께 걸립니다.

**연도·시험 범위 필터**로 "2023년 이후 수능만" 같이 미리 걸러 두실 수도 있습니다.

다 고르셨으면 **문항집 만들기**를 누르세요. A4 2단으로 조판된 미리보기가 나옵니다.
**인쇄 / PDF 저장**을 누르시면 그대로 인쇄되거나 PDF로 저장됩니다.

> 💡 PDF 파일명은 자동으로 추천됩니다. `지구과학Ⅱ 해수의 운동_19문항_정답_260904.pdf` 처럼요.
> 정답을 켜고 저장하면 `_정답`이 붙으니, 교사용과 학생용 파일이 섞이지 않습니다.

> 💡 만든 문항 목록은 **저장해 두실 수 있습니다.** 이름을 붙여 저장하면 나중에 그대로 불러와 다시 편집하실 수 있습니다.

> 💡 인쇄물에는 저작권 안내나 출처 표시가 **찍히지 않습니다.** 화면에서만 보입니다.

## 이미 PDF를 갖고 계시다면

내려받는 단계를 건너뛰고 폴더만 알려 주시면 됩니다.

```bash
python scripts/gw.py detect --subject earth-science-ii --input "C:\내려받은기출"
```

**문제지·정답지·해설지는 파일 이름이 없어도 괜찮습니다.** 파일 안을 읽어서 가릅니다.
이름이 붙어 있는데 내용과 다르면 **내용이 이깁니다**(그때는 리포트에 알려 드립니다).

> ⚠️ **다만 폴더 이름은 회차로 지어 주세요.** `2025_고3_3월학평` 처럼요.
> 몇 학년도 무슨 시험인지는 파일 안에 안 적혀 있는 경우가 실제로 있습니다
> (EBSi 학평 문제지에는 월 표기가 아예 없습니다). 폴더 이름이 그 단서가 됩니다.

> ⚠️ 스캔한 PDF(글자가 이미지인 것)는 내용으로 종류를 가릴 수 없습니다.
> 그때는 파일 이름에 `문제`·`정답`·`해설` 중 하나만 넣어 주시면 됩니다.

## 새 과목 추가하기

30분이면 됩니다. 자세한 순서는 [`docs/NEW_SUBJECT.md`](docs/NEW_SUBJECT.md)에 있고, 요약하면 이렇습니다.

1. `subjects/_template/` 폴더를 복사해서 새 과목 폴더를 만듭니다.
2. `subject.json`에 과목 정보를 채웁니다.
3. `python scripts/gw.py standards --draft-keywords --subject <과목>` 으로 키워드 사전 초안을 만듭니다.
   초안은 `workspace/<과목>/keywords.json` 에 생깁니다. 마음에 드시면 `--install` 로 저장소에 넣으세요.
   (바로 저장소에 쓰지 않는 이유: 저장소에 없던 파일이 생기면 나중에 `git pull` 이 멈춥니다.)
4. **회차 하나만 먼저** 끝까지 돌려 보고 확인 이미지를 봅니다.
5. 괜찮으면 전체를 돌립니다.

> ⚠️ 4번을 꼭 지켜 주세요. 판형 예외는 과목마다 새로 나옵니다. 380문항을 다 망친 뒤에 알면 늦습니다.

## 자주 묻는 것

**Q. `auto=0, queued=전부` 라고 나옵니다. 고장인가요?**

아닙니다. 정상입니다. 그 과목은 아직 **분류기가 보정되지 않은 상태**라 자동 분류를 하지 않고 전부 확인 목록으로 보냅니다.
검증되지 않은 채로 자동 분류하면 틀린 단원이 조용히 박히기 때문에, 일부러 그렇게 해 두었습니다.

**그리고 이 상태에서도 학습지는 지금 만드실 수 있습니다.** `build`가 회차별 탭으로 내보냅니다.
단원별로 고르고 싶으실 때만 아래가 필요합니다.

```bash
# ① 확인 목록을 AI가 판정 → 반영
python scripts/gw.py classify --subject <과목> --apply <판정결과.json>
# ② 판정된 것 일부로 배우고, 나머지로 채점한다
python scripts/gw.py classify --subject <과목> --learn     --only 2024_수능,2025_수능
python scripts/gw.py classify --subject <과목> --calibrate --only 2026_수능
```

> ⚠️ **`--learn` 과 `--calibrate` 를 같은 문항으로 돌리면 안 됩니다.**
> 배운 문항으로 채점하면 표본이 0이 되어 임계값이 영영 안 나옵니다. 회차를 나눠 주세요.

> ⚠️ **문항 수보다 "성취기준 하나당 몇 건인지" 가 중요합니다.**
> 한 성취기준에 **2건 이상** 모여야 거기서 용어를 뽑습니다.
> 한 회차(20문항)를 판정해도 성취기준 18개에 하나씩 흩어지면 배울 게 거의 없습니다 — **2~3회차**는 필요합니다.

지구과학Ⅱ는 **8회차를 학습**해서 정확도가 0.40 → 0.89가 됐습니다.
한 회차만으로는 오히려 내려갈 수 있으니(실측 0.10 → 0.05), `--calibrate` 로 이득이 났는지 직접 확인하세요.

**Q. 정답이 비어 있는 문항이 있습니다.**

세 가지 방법으로 읽은 정답이 서로 다 다르면 채우지 않고 비워 둡니다. 추측해서 채우면 틀렸을 때 아무도 못 찾습니다.
`reports/extract.json`에 어느 회차인지 적혀 있으니, 그 회차만 확인해 주시면 됩니다.

**Q. 선택지가 0개라고 나옵니다.**

선택지가 **분수나 도형 그림**인 문항입니다. 화학·물리에 회차당 두세 개씩 있습니다.
글자가 아니라 그림이라 텍스트로 옮길 수가 없어서, 오류가 아니라 '전사 대기'로 표시됩니다.
문항집을 만드는 데는 아무 문제 없습니다 — 잘라낸 이미지가 본체니까요.

**Q. 명령이 실패했습니다.**

각 명령은 `workspace/<과목>/reports/` 안에 결과 파일을 남깁니다. 그 안의 `attention` 항목을 보시면 무엇이 문제인지 적혀 있고, `next`에 다음에 실행할 명령까지 들어 있습니다.

**Q. 만든 학습지를 다른 선생님께 드려도 되나요?**

## 국어·수학·영어는 아직 안 됩니다

솔직하게 말씀드립니다. 지금 검증된 것은 **탐구 영역 판형**뿐입니다.

- **국어·영어**는 지문 하나에 문항이 여러 개 묶여 있어서, 문항 단위로 자르면 지문이 없어집니다.
- **수학**은 수식이 그림처럼 그려져 있어 글자로 읽어낼 수가 없고, 단답형에는 선택지가 없습니다.

무엇을 만들어야 하는지는 [`docs/LAYOUTS.md`](docs/LAYOUTS.md)에 분석해 두었습니다.
만드셨다면 이슈나 PR로 알려 주시면 정말 감사하겠습니다.
