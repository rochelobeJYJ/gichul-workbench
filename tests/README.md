# 테스트

의존성 없이 표준 라이브러리 `unittest` 만 쓴다. 저장소 어디서나:

```bash
python -m unittest discover -s tests -v
```

## 무엇을 지키는 테스트인가

여기 있는 것은 전부 **실제로 한 번 조용히 틀렸던 자리**다.
`docs/PITFALLS.md` 의 항목과 1:1로 이어진다 — 각 테스트 docstring에 어느 항목인지 적어 두었다.

기출 문항이 필요한 테스트는 없다. **저작물은 저장소에 들어가지 않는다**(`docs/CONTRACT.md` 0절).
그래서 여기서 잡히는 것은 계약·파서·식별자 수준이고,
크롭 품질처럼 눈으로 봐야 하는 것은 잡히지 않는다. 그건 대지(contact sheet)의 몫이다.

## 기여하실 때

동작을 바꾸는 PR이라면 **그 동작을 고정하는 테스트를 함께** 주시면 좋겠습니다.
특히 판형 예외를 고치셨다면, 그 판형이 어떻게 생겼는지가 테스트에 남아야
다음 사람이 되돌리지 않습니다.
