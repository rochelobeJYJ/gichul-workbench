# 다운로드 프로바이더

`gw download` 는 두 곳에서 기출 원본을 가져온다. **한쪽만으로는 자료가 다 모이지 않는다.**

| | EBSi (`ebsi`) | 평가원 공식 (`kice-official`) |
|---|---|---|
| 출처 | ebsi.co.kr 기출문제 목록 | suneung.re.kr 게시판 (수능 1500234 / 모평 1500236) |
| 문제지 | O | O (원본) |
| 정답 | O (png 이미지) | O (과목별 pdf, 구 회차는 jpg) |
| **해설** | **O — 여기만 있다** | **X — 평가원은 배포하지 않는다** |
| 수능·6월·9월 모평 | O | O |
| 전국연합학력평가(학평) | O | **X — 시·도교육청 주관이라 게시판에 없다** |
| 연도 범위 | 대략 2015 이후가 안정적 | 2005학년도부터 |
| 과목 지정 방식 | 숫자 `subject_id` (사이트 내부 코드) | 영역 ZIP 을 받아 **파일명 별칭**으로 골라냄 |
| 로그인 | 불필요 | 불필요 |

`--provider auto`(기본)의 판단은 `providers/__init__.py:provider_chain()` 한 곳에 있다.
해설이면 EBSi, 학평이면 EBSi, 그 밖의 문제·정답은 평가원 먼저 → 실패하면 EBSi.

## ★ 시행일 함정 (가장 많이 당하는 것)

**두 사이트의 목록은 모두 '학년도'가 아니라 '시행일' 기준이다.**

| 회차 | 실제 시행일 | 목록에 찍히는 연/월 |
|---|---|---|
| 2021학년도 수능 | 2020-12-03 (코로나 연기) | 2020 / **12** |
| 2023학년도 9월 모평 | 2022-08-31 | 2022 / **08** |
| 2020년 고3 3월 학평 | 2020-04-24 (코로나 연기) | 2020 / **04** |

그래서 **월로 회차를 거르면 안 된다.** 옛 구현이 `--months 06,09,11` 로 못 박는 바람에
위 회차들을 조회 자체에서 날렸다. 지금 구현은 이렇게 한다.

1. 조회는 넉넉한 월 범위로 한다 (`ebsi.py:MONTH_HINTS` — 수능이면 11·12월, 9월모평이면 8·9·10월).
2. 회차 종류는 **목록 제목**으로 판정한다 (`ebsi.py:classify_exam`).
   `대학수학능력시험` / `9월 모평(평가원)` / `3월 학평(서울)`.
3. 학년도는 제목의 `2021학년도` 를 1순위로 믿고, 없으면 `시행 달력연도 + 1` 로 환산한다.
4. 회차 이름의 월과 실제 시행월이 다르면 리포트 `attention` 에 `info` 로 남긴다.

제목 파싱에서 한 번 더 조심할 곳: **공백을 지우면 안 된다.** `고3 9월 모평` 의 공백을 없애면
`고39월` 이 되어 월을 `39` 로 읽는다. 실제로 이것 때문에 모평 회차 전체를 놓쳤다.

## EBSi

### 페이지네이션 (원본의 버그)

AJAX 응답은 한 페이지에 15행이다. 페이징 파라미터는 응답 안의 hidden input 이름 그대로
`currentPage` 이고, 총건수는 `<em class="tot">N개</em>` 에 있다.
1페이지만 읽던 옛 구현은 16번째 이후 회차를 "존재하지 않음"으로 보고했다.
실측(지구과학Ⅱ, 2020~2025 시행연도): 총 18건 중 3건이 2페이지에 있었고,
그 3건이 정확히 **2021학년도 수능·9월모평·6월모평**이었다.

멈추는 조건은 셋을 함께 본다 — 총건수 도달 / `goPage(N)` 링크 소진 / 안전핀 60쪽.
하나만 믿으면 사이트가 조금만 바뀌어도 다시 조용히 놓친다.

### 과목 ID

`subjects/<slug>/subject.json` 의 `providers.ebsi.subject_id` 다. 이 값은 **어디에도 문서화되어
있지 않고 교육과정이 바뀌면 달라진다.** 그래서 표를 코드에 박아두지 않고 실측한다 → `--probe`.

계열별로 값이 다를 수 있어 `providers.ebsi.national` 하위 블록으로 학평용 ID 를 덮어쓸 수 있다.
다만 **2025년 9월 현재 EBSi 고3 목록(D300)은 수능·모평과 학평이 같은 과목ID 를 쓴다.**
학평 전용 ID 로 0건이 나오면 상위 ID 로 자동 재조회하고 `warn` 을 남긴다.

학년별 목록 대상 코드: 고1 `D100` / 고2 `D200` / 고3 `D300`.
고3 목록에는 평가원 모평과 교육청 학평이 **섞여 있다** — 그래서 제목 판정이 필요하다.

## 평가원 공식

### 탐구는 ZIP 한 덩어리다

탐구 영역은 8~9과목이 ZIP 하나로 묶여 올라온다. 과목 하나를 꺼내려면 ZIP 을 받아서 열어야 하고,
**내부 파일명이 해마다 다르다.**

```
2026학년도 : 08 지구과학Ⅱ_문제지.pdf
2021학년도 : 08 과탐(지구과학 II).pdf
2010학년도 : 지구과학II.PDF        ← cp949 로 저장, UTF-8 플래그 꺼짐
```

그래서 정규식이 아니라 **과목별 별칭표**로 맞춘다. 별칭은 코드가 아니라
`subject.json` 의 `providers.kice.aliases` 에 있다. 새 과목을 넣을 때 여기를 채워야 한다.

두 가지 방어가 들어 있다. 둘 다 실제 사고에서 나온 것이다.

- **CP949 복원** — 구 ZIP 은 UTF-8 플래그(0x800)가 꺼져 있어 `zipfile` 이 cp437 로 잘못 읽는다.
  `'┴÷▒╕░·╟╨I.PDF'` 를 되감아 cp949 로 다시 읽어야 `'지구과학I.PDF'` 가 나온다.
- **로마숫자 토큰화** — `지구과학I` 필터는 부분 문자열이라 `지구과학II` 파일에도 걸린다.
  전각 Ⅰ/Ⅱ 를 반각으로 통일한 뒤 `#1#`/`#2#` 토큰으로 치환해서 끊는다
  (`providers/__init__.py:normalize_roman`).

### 과목별로 안 쪼갠 회차가 있다

2021학년도 수능 정답표는 `4교시_과학탐구영역_정답표.pdf` 한 장에 8과목이 다 들어 있다.
이럴 때는 그 통짜 파일을 저장하고 `attention` 에 `info` 로 남긴다 — 이후 단계에서 해당 과목
쪽수만 잘라내야 한다. **조용히 넘어가지 않는 것이 요점이다.**

### 구 교육과정 영역명

2013학년도까지는 국어/수학/영어가 **언어/수리/외국어**였다. 한국사는 2017학년도부터 독립 영역이고
그 전에는 사회탐구 ZIP 안에 있다. `kice_official.py:AREA_HISTORY` 가 연도별 영역명 후보를 만들고,
첫 후보로 0건이면 다음 후보로 재시도한 뒤 `info` 를 남긴다.

`제2외국어/한문` 은 서버 검색 파라미터가 연도별로 깨져 있어 영역 파라미터를 아예 보내지 않고
전체를 받아 클라이언트에서 거른다 (`CLIENT_FILTER_AREAS`).

### 예의

요청 사이 0.5~1.5초 랜덤 딜레이가 **기본값**이다. 공공 사이트이고 한 번에 수십 회차를 긁는다.
`--fast` 는 소량 재시도용이다. 대량 수집에 쓰지 마라.

## `--probe` — 새 과목을 등록하는 첫걸음

사탐 9과목의 `subject_id` 를 아무도 모른다. 알아내는 방법은 사이트에 직접 물어보는 것뿐이다.

```
python scripts/gw.py download --probe --area 사회탐구 --year 2024 --exam 수능
```

리포트(`workspace/_probe/reports/download_probe.json`)에 이렇게 남는다.

```
과목        subject_id  form_field    area_order  rows_found  kinds_found
생활과 윤리   63002       sFormPartSoc  5           1           problem/answer/solution
한국지리      141         sFormPartSoc  5           1           problem/answer/solution
…
```

각 행에 `subject_json` 조각이 함께 들어 있어 `subject.json` 의 `providers` 에 그대로 붙여 넣으면 된다.
`--year`/`--exam` 을 주면 그 회차에 자료가 실제로 있는지까지 확인하고, 평가원 게시판 쪽 게시물과
첨부 파일명도 함께 보여준다(별칭을 무엇으로 쓸지 정할 근거).

ZIP **내부** 파일명까지는 probe 가 보여주지 않는다(수십 MB 를 받아야 해서 probe 가 무거워진다).
한 회차를 실제로 받아 보고 `attention` 메시지로 확인하는 것이 빠르다.

## 판형별 변형 (아직 비어 있는 자리)

탐구(`tamgu-1q1block`)는 회차·과목당 파일이 하나뿐이라 고를 것이 없다.
다른 판형은 **같은 회차에 여러 판본**이 올라온다.

- `math-mixed` : 수리 가형 / 나형 (구 교육과정), 확률과통계·미적분·기하 선택
- `passage-group` : 국어·영어 홀수형 / 짝수형, 영어 듣기 음원·대본 동봉

어느 판본을 정본으로 삼을지는 `subject.json` 에 없는 정보라 지금 결정할 수 없다.
그래서 `download.py:LAYOUT_PICKER` 에 자리만 두고 `NotImplementedError` 로 후보 목록을 알려준다.
채울 때 할 일은 둘이다.

1. `subject.json` 에 판본 선택 필드를 넣자고 제안한다 (CONTRACT 3절 스키마 변경).
2. `LAYOUT_PICKER` 에 해당 판형의 전략 함수를 등록한다. 시그니처는
   `picker(cands: list[Candidate], chain: list[str]) -> list[Candidate]` — 시도 순서를 돌려준다.

## 회차별 manifest

`workspace/<slug>/sources/<exam_id>/manifest.json` 하나가 그 회차의 출처 기록이다.

```json
{
  "schema_version": 2,
  "exam_id": "2021_수능", "slug": "earth-science-ii", "subject_label": "지구과학Ⅱ",
  "year": 2021, "year_semantics": "academic", "exam": "수능", "grade": null,
  "sitting_date": "20201203",
  "status": "verified", "ok": true, "missing": [],
  "files": {
    "problem": {
      "path": "problem.pdf", "provider": "kice-official",
      "source_url": "https://www.suneung.re.kr/boardCnts/fileDown.do?fileSeq=…",
      "record_title": "문제 및 정답 2020-12-04 / 4교시_과학탐구영역.zip",
      "zip_member": "08 과탐(지구과학 II).pdf",
      "sha256": "0b75af70…", "size_bytes": 2640148,
      "actual_extension": ".pdf", "verified": true
    }
  }
}
```

**파일명만으로는 나중에 아무것도 재현할 수 없다.** 그래서 `source_url` 과 `sha256` 을 반드시 남긴다.
이후 단계는 파일명이 아니라 이 둘로 원본을 식별한다.

검증 기준(`providers/__init__.py:verify_bytes`): 매직넘버로 실제 형식을 판정하고, 문제·해설은 PDF 만,
정답은 PDF/PNG/JPG 를 인정하며, 1KiB 이하는 거부한다(오류 안내 페이지가 파일인 척 저장되는 것 방지).
검증에 실패하면 저장하지 않고 다음 프로바이더로 넘어간다.
