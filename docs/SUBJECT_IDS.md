# SUBJECT_IDS — 탐구 영역 17과목 값의 출처와 공백

`subjects/<slug>/subject.json` 에 채운 값이 **어디서 왔는지**와 **아직 비어 있는 것**을 적는다.
아래 표의 EBSi 값은 전부 **2026-09-03 에 사이트에서 실측**했다(`gw download --probe`). 추측한 값은 없다.

## 0. 앞선 판의 서술을 실측으로 바로잡음

이전 판에는 이렇게 적혀 있었다 — *"EBSi 다운로드는 두 계열(KICE 수능·모평 / 학평)이 완전히 다른
`subject_id` 를 쓴다"*, 그리고 *"KICE 계열 사회탐구 9과목의 subject_id 는 어디에도 없다"*.
**둘 다 틀렸다.** 실측 결과는 이렇다.

1. **과목ID 를 가르는 축은 계열이 아니라 학년 목록(`targetCd`) 이다.**
   고3 목록(`D300`)의 subject_id **하나**가 수능·6월모평·9월모평·고3 학평을 전부 담는다.
   예: 한국지리 `141` 로 조회하면 `2026학년도 대학수학능력시험 한국지리` 와
   `고3 3월 학평(서울) 한국지리` 가 같은 목록에 함께 나온다.
2. **옛 표가 '학평 계열'이라 부르던 값은 실은 고2 목록(`D200`) 용이다.**
   대조 실측 — 지구과학Ⅰ `17041` 은 `D300` 에서 2019·2026년 모두 0건이고,
   `D200` 에서는 2015~2025년 44건이 정상 조회된다. 한국지리 `17029` 도 같다.
   옛 '학평 ID' 가 존재하는 13과목 전수에서, 고3 목록 조회 결과는 예외 없이 0건이었다
   (2026년·2019년 3월학평 두 해로 각각 확인). Ⅱ 과목 4개는 옛 표에 항목 자체가 없었다.
3. 그래서 사탐 9과목의 값은 '어디에도 없던' 것이 아니라, **고3 목록 페이지의 과목 체크박스에
   그대로 있었다.** 아무도 그 페이지를 읽지 않았을 뿐이다.

이 정정에 따라 `scripts/providers/ebsi.py` 의 `_conf_for()` 를 고쳤다 — `providers.ebsi.national`
블록을 '학평일 때'가 아니라 **'targetCd 가 D300 이 아닐 때'** 적용한다. 예전 코드는 고3 학평을
고2 ID 로 조회해 0건을 받고 "national 이 낡았을 수 있다"는 **틀린 진단**을 붙였다.
(PITFALLS 7-3 '조용한 기본값' 과 같은 종류의 사고다.)

### `providers.ebsi.national` 은 학년별 블록이다 (2026-09-04 개편)

고2 ID 를 담을 자리는 있었지만 **고1을 담을 자리가 없었다.** 학년은 셋이고 목록도 셋이다.
그래서 키를 학년으로 편다. 자세한 근거는 `docs/PROVIDERS.md` '과목 ID' 절과
`ebsi.py:_conf_for` 주석에 있다. 요약만 옮기면:

```json
"national": {
  "2": {"subject_id": "17042", "form_field": "sFormPartSci", "area_order": "6"},
  "1": {"absent": true, "why": "고1 목록에는 통합과학뿐 — 대응 과목 없음 (2026-09-04 실측)"}
}
```

- `"3"` 칸은 두지 않는다. 고3은 최상위 `subject_id` 하나로 전부 조회된다(위 표).
- `{"absent": true}` 는 **'아직 안 채웠다'와 '실측했고 없다'를 가른다.** 고1 목록에는 탐구
  선택과목이, 고2 목록에는 Ⅱ 과목이 아예 없다. 비워 두면 도구가 "실측해서 채워라"라고
  안내하는데 채울 값이 없다.
- 옛 평면형도 계속 읽는다(고2로 해석 + `info`). 아직 안 옮긴 파일: `life-ethics`,
  `ethics-thought` — 소유가 다를 뿐 값은 이 표에 있다.
- 고1 학년 목록(`D100`)의 통합사회·통합과학 ID 는 고2 목록의 것과 **또 다르다**
  (통합사회 D100 `140072` / D200 `140220`, 통합과학 D100 `140073` / D200 `140221`).
  '학년이 축' 이라는 말이 통합과목에서도 그대로 성립한다는 증거다.

### 학년마다 치르는 학평이 다르다 (2026-09-04 목록 실측)

| 학년 | 목록 | 학평 회차 | 평가원 |
|---|---|---|---|
| 고3 | `D300` | 3월(서울) · **4월/5월**(경기) · 7월(인천) · 10월(서울) | 6·9월 모평, 수능 |
| 고2 | `D200` | 3월(서울) · 6월(부산) · 9월(인천) · **10월/11월**(경기) | — |
| 고1 | `D100` | 고2와 같은 네 회차 | — |

경기 주관 회차는 이름이 해마다 옮겨다닌다(고3 2024년까지 4월 → 2025·2026년 5월,
고2 2023년 11월 → 2024·2025년 10월). 그래서 `common/ids.py` 의 `EXAM_ALIASES` 에
`5월학평`·`6월학평`·`9월학평`·`11월학평` 을 더했다. 이 넷이 없던 동안 해당 회차는
`info` 한 줄만 남기고 조용히 건너뛰어지고 있었다.

### 알아둘 것

- **정치와 법·물리학Ⅰ·물리학Ⅱ 는 2021학년도부터만 있다.** 2015개정에서 과목명이 바뀌며
  (`법과 정치`→`정치와 법`, `물리Ⅰ`→`물리학Ⅰ`) EBSi 가 항목을 새로 팠기 때문이다.
  2020학년도 이전 회차는 '이전과목' 묶음(`socPast`/`sciPast`) 안에 **다른 ID** 로 있다 —
  실측: 법과정치 `66003`, 물리Ⅰ `152`, 물리Ⅱ `153`. 필요하면 별도 슬러그로 등록해야 한다.
- **Ⅱ 과목(물리학Ⅱ·화학Ⅱ·생명과학Ⅱ·지구과학Ⅱ)도 고3 학평을 시행한다.**
  앞선 판의 *'학평 미시행'* 서술은 틀렸다. 3월학평만 없고 4·5·7·10월 학평이 같은 ID 로 조회된다
  (실측 예: 화학Ⅱ 2024-04-30 / 2025-04-30 / 2025-10-14 / 2026-07-08. 지구과학Ⅱ 155 로도
  2024·2025년 각 4회차 확인). 다만 고2 목록에는 Ⅱ 과목 항목 자체가 없어
  `providers.ebsi.national` 의 `"2"` 칸을 `{"absent": true}` 로 적는다 — 비워 두는 것과 다르다.
- ~~EBSi 목록에는 `5월학평` 회차가 있는데 … 지금은 건너뛴다~~ → **2026-09-04 해결.**
  `5월학평`·`6월학평`·`9월학평`·`11월학평` 을 `EXAM_ALIASES`·`GRADE_BEARING`·`exam_sort_key`,
  `download.py:NOMINAL_MONTH`, `ebsi.py:MONTH_HINTS` 에 함께 넣었다.
- 고1 목록(`D100`)에는 탐구 선택과목이 없다(통합사회 `140072`·통합과학 `140073` 뿐).
  그래서 이번에 옮긴 13개 과목은 `national."1"` 이 전부 `{"absent": true}` 다 —
  추측이 아니라 실측 결과다. (남은 4개: `earth-science-*` 레퍼런스 구현 2개,
  `life-ethics`·`ethics-thought` 다른 담당 소유 2개.)

## 2. `kice.aliases` — 평가원 파일명 오기 방어표

`D:/codex_work/programs/kice_down/main.py` 의 `OLD_SUBJECT_FILTERS` 에서 손실 없이 옮긴 값이다.
2024학년도 수능 ZIP 으로 실제 확인한 내부 파일명은 `06 세계사_문제.pdf`, `09 사회·문화_문제.pdf`
꼴이고 별칭이 정상적으로 걸렸다.

다만 가운뎃점은 코드포인트가 여러 종류다 — 같은 회차 사회·문화 **문제지 머리글**은 반각
`･`(U+FF65) 를 쓴다. 파일명에서 이 표기를 만나면 `사회문화` 별칭이 안 걸려 ZIP 안에서 과목을
못 찾고 통째로 실패하므로, `providers/__init__.py` 의 `normalize_name()` 이 `･`·`‧` 도 지우게 했다.

## 5. 학평 실증 결과 (2026-09-04)

학평 경로는 코드만 있고 한 번도 돌려본 적이 없었다. 네 회차를 끝까지 돌렸다 —
과탐 화학Ⅰ · 사탐 한국지리 × `2025_고3_3월학평` · `2025_고2_3월학평`.

| 회차 | 문항 | 배점 합 | 3점 문항 | 정답 대조 축 | 실물 정답표 손 대조 |
|---|---|---|---|---|---|
| 화학Ⅰ 2025_고3_3월학평 | 20 | 50 | 10 | **2축** (정답지 PNG 원문자 + 해설지 첫머리 표) | 20/20 |
| 화학Ⅰ 2025_고2_3월학평 | 20 | 50 | 10 | **2축** | 20/20 |
| 한국지리 2025_고3_3월학평 | 20 | 50 | 10 | **2축** | 20/20 |
| 한국지리 2025_고2_3월학평 | 20 | 50 | 10 | **2축** | 20/20 |

- **문항 수·배점은 수능과 같다.** `question_count: 20` / `points_total: 50` 이 그대로 통했다 —
  탐구에 한해 CONTRACT 3절 스키마를 늘릴 이유가 없었다.
- **정답지가 PNG 라 원문자 픽셀 대조가 유일한 정답지 축이다.** 네 회차 모두 텍스트 0자이고
  Windows OCR 은 ①~⑤ 를 `ㅅ` 으로, `11`·`12`·`19` 를 `77`·`72`·`79` 로 읽는다.
  `parse_circled_answer_image` 가 네 회차 모두 20/20 을 읽었다.
- **해설지 정답표는 번호에 마침표가 없다**(`1 ① 2 ⑤` 가 줄바꿈으로 이어진다).
  `parse_paired_number_table` 이 그 판형을 읽는다 — 학평 실물로 재현·검증했다.
- **세 축 중 pdfplumber 축만 죽는다.** 네 회차 전부 0건.
  겹친 원인 둘. (1) 학평 정답지는 PDF 가 아니라 PNG 라 `extract_tables` 경로를 아예 못 탄다.
  (2) 대체 경로인 해설지 layout 텍스트는 2단 편집을 펴면서 정답표와 본문을 한 줄로 합친다.
  실제로 나온 줄: `1 1 2 5 3 3 4 4 5 3 [오답풀이] ㄹ. 충남과 울산은 제조업 출하액이 비슷` .
  토크나이저가 '숫자·기호만으로 된 줄' 을 요구하므로 이 줄은 통째로 버려진다.
- **복구 방법은 실측해 뒀다.** layout 텍스트 대신 `page.extract_words()` 를 쓰면
  **원문자 ①~⑤ 가 살아 있다**(NFKC 가 눕히기 전 단계다). 토큰을 `(top, x0)` 로 정렬해
  `번호 + 원문자` 쌍이 1..20 을 정확히 덮는 구간만 인정하는 15줄짜리 시제품으로 **네 회차 모두
  20/20 을 읽었고 다른 두 축과 완전히 일치**했다. 번호와 정답이 글자 모양으로 구분되므로
  '정답 자리에 배점이 들어앉는' 종류의 사고가 원리적으로 불가능하다.
  다만 `extractlib/answers.py` 는 이 작업의 소유 밖이라 반영하지 않았다.

## 6. 재현 방법

```bash
# 영역 안의 과목 목록과 subject_id 를 사이트에서 실측 (고3 목록)
python scripts/gw.py download --probe --area 사회탐구 --year 2024 --exam 수능 --workspace /tmp/probe
python scripts/gw.py download --probe --area 과학탐구 --year 2026 --exam 수능 --workspace /tmp/probe2

# 고2 목록의 값이 다르다는 것을 보려면
python scripts/gw.py download --probe --area 사회탐구 --grade 2 --workspace /tmp/probe3

# 채운 값이 진짜인지 — 받지 않고 목록까지만 확인
python scripts/gw.py download --subject world-history --years 2024 --exams 수능 \
       --kinds problem,answer,solution --dry-run --workspace /tmp/dry
```

# 학평 한 회차를 끝까지 (학평은 --grade 가 필수다. 연도는 **달력연도**다)
python scripts/gw.py download --subject chemistry-i --years 2025 --exams 3월학평 --grade 3        --workspace /tmp/hp
python scripts/gw.py detect  --subject chemistry-i --workspace /tmp/hp
python scripts/gw.py crop    --subject chemistry-i --workspace /tmp/hp
python scripts/gw.py extract --subject chemistry-i --workspace /tmp/hp
```

리포트는 `<workspace>/reports/download_probe.json` 의 `ebsi_subjects` 에 과목별로
`subject_id`·`form_field`·`area_order` 와 그대로 붙여 넣을 `subject_json` 조각이 들어 있다.
