# 판형별 대응

크롭과 추출 전략은 `subject.json` 의 `layout` 값으로 갈린다.
지금 실동작하는 것은 `tamgu-1q1block` 하나뿐이다. **나머지는 솔직히 미완성이다.**

---

## `tamgu-1q1block` — 탐구 영역 (검증됨)

사회탐구 9과목, 과학탐구 8과목.

| 특성 | 값 |
|---|---|
| 편집 | 표준 2단 |
| 문항 경계 | 문항 하나가 한 블록. 컬럼을 넘어가는 경우는 있어도 서로 겹치지 않는다 |
| 문항 수 | 20 |
| 배점 합 | 50 (2점·3점 혼합) |
| 선택지 | 5개, `①②③④⑤` |

이 판형이라서 가능한 것: 문항 번호의 x좌표로 컬럼을 판정하고, 다음 번호 직전까지를
한 문항으로 잘라내는 것. **이 가정이 깨지는 순간 아래 판형들이 된다.**

38회차 760문항에서 확인된 예외는 `PITFALLS.md` 2장에 있다.

## `passage-group` — 국어·영어 (미구현)

### 무엇이 다른가

**지문 하나에 문항 여러 개가 묶인다.** 국어 독서·문학은 지문 1개에 문항 3~5개,
영어는 장문 독해에 2~3개. 문항만 잘라내면 지문이 없어 문제가 성립하지 않는다.

### 필요한 것

- 크롭 단위가 **문항이 아니라 지문+문항군**이 되어야 한다.
- 문항 하나만 골라 문항집에 넣는 것이 불가능하다. 최소 단위가 문항군이다.
- 문항군의 시작(지문 시작)을 찾는 규칙이 필요하다. 국어는 `[1~3] 다음 글을 읽고 물음에 답하시오.`
  같은 안내문이 지문 앞에 온다. 이걸 앵커로 쓸 수 있다.
- 문항 수가 회차·과목마다 다르다(국어 45문항, 영어 45문항). `question_count` 로 처리된다.
- 영어는 듣기 17문항이 앞에 있고, 이건 지면에 선택지만 있다. 별도 취급이 필요하다.

### 데이터 모델에 필요한 변경

`items/<qid>.json` 에 `group_id` 와 `shared_passage` 개념이 있어야 한다.
현재 계약에는 없다. 추가할 때 `docs/CONTRACT.md` 를 함께 고쳐야 한다.

## `math-mixed` — 수학 (미구현)

### 무엇이 다른가

- **객관식 + 단답형이 섞여 있다.** 단답형에는 선택지가 없다.
  "선택지 5개" 검증이 통째로 무의미해진다.
- **수식이 벡터로 그려진 경우가 많다.** 텍스트 추출이 깨지거나, 되더라도 순서가 뒤엉킨다.
  `\frac` 같은 구조가 평문으로 뭉개진다.
- 배점이 2·3·4점이고 합이 100점이다. `points_total` 로 처리되지만
  단답형 배점 규칙이 객관식과 다르다.
- 선택과목(확률과 통계 / 미적분 / 기하)이 공통과목 뒤에 붙는다. 한 PDF에 여러 과목이 들어 있다.

### 필요한 것

- `extraction_mode: "vision"` 을 기본값으로 두는 편이 현실적이다.
  수식을 텍스트로 복원하려 애쓰는 것보다 이미지를 본체로 삼는 게 낫다.
- 단답형 판별과 별도 검증 규칙.
- 한 PDF 안에서 선택과목 구간을 나누는 로직.

## 새 판형을 추가할 때

1. `scripts/common/subjects.py` 의 `KNOWN_LAYOUTS` 에 값과 한 줄 설명을 추가한다.
2. `crop.py` / `extract.py` 의 전략 분기에 구현을 붙인다.
   **기존 `tamgu-1q1block` 경로를 건드리지 마라.** 검증된 것을 깨뜨리는 게 가장 비싸다.
3. 한 회차만 끝까지 돌려 대지를 눈으로 확인한다.
4. 이 문서에 무엇이 달랐는지 적는다. 다음 사람이 같은 것을 다시 알아내지 않도록.

## LLM에게

사용자가 국어·수학·영어를 들고 오면 **되는 척하지 마라.**
탐구 판형은 검증됐지만 그 과목들은 어댑터가 없다는 사실을 먼저 알리고,
위에 적힌 차이를 근거로 무엇을 함께 만들어야 하는지 설명해라.
그리고 만들었으면 이 문서를 갱신하고 이슈로 제안해라.
